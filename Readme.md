# ADAMS Assignment 1

## About this class

가상의 연구를 설계하고, 데이터를 직접 생성해 분석하는 과제입니다. 시뮬레이션을 반복해 분석 결과가 얼마나 안정적인지 확인합니다.

## Work A (Research Proposal)

연구 주제와 가설을 정하고, 어떤 데이터를 어떻게 분석할지 계획합니다.

[연구 계획서](https://docs.google.com/document/d/11vcbV-IfnBoOlFVFMPqQ8buG-g8l_m7OCkh54MbQASw/edit?tab=t.0)

## Work B (Synthetic Data)

실제 효과가 **있는 데이터**와 **없는 데이터**를 생성하고 시각화합니다.

## Work C (Simulated Analysis)

두 데이터를 분석한 뒤 시뮬레이션을 반복합니다. 분석이 효과를 얼마나 잘 찾아내고, 얼마나 자주 잘못 판단하는지 확인합니다.

## Work D (Simulation with QRP)

결과에 영향을 줄 수 있는 분석 방법(QRP)을 추가합니다. Work C와 비교해 결과가 얼마나 달라지는지 확인합니다.
